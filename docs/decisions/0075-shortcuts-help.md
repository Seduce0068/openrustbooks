## 背景

`[` `]` `+` `-` `d` `Alt+←` `Alt+→` などのショートカットが実装されているが、
利用者が一覧を確認できる手段が無かった。

## 決定

- `?` キー（Shift+/）でネイティブ `<dialog>` を `showModal()` で開く。
- ツールバーに `?` ボタン（`<button id="reader-help">`）を置く。
- ダイアログにショートカット一覧を表示する:
  - `[` / `]`: 前の章 / 次の章
  - `+` / `-`: 文字サイズ
  - `d`: ダーク表示
  - `Alt+←` / `Alt+→`: 戻る / 進む
  - `?`: このヘルプ
- Esc / 閉じるボタンで閉じる（ネイティブモーダルの標準動作を利用）。
- 入力欄にフォーカスがあるときは `?` を奪わない（既存のキーハンドラの
  規則を維持）。

## 選択肢と根拠

| 選択肢 | 判断 |
| --- | --- |
| ネイティブ dialog + `?`（採用） | 追加依存なしで発見性が向上する |
| ツールチップだけ | 一覧として確認できない |
| 独自オーバーレイ | フォーカス管理を自作する必要がある |

## 影響

- 利用者がショートカットを知らなくても `?` で確認できる。
- 既存のキーボード操作・削除確認ダイアログには影響しない。
- 追加依存は無い。

## 検証

- ヘッドレス Chrome 157 と `tools/verify-web-reader.py` の E2E 206 項目が
  5 回連続で成功。
- `?` キーでダイアログが開き、主要ショートカットが含まれ、
  閉じるボタンで閉じることを確認した。
- `cargo test --all-targets --locked` は 125 件成功。
