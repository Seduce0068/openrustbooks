## 背景

ADR-0053 で世代号による古い適用の破棄を導入したが、世代チェックは
`apply_position_frame` のメインコールバック先頭にのみあった。画像待ちの
再試行ループ（`setTimeout(0)`、最大 2000ms）には世代チェックが無く、
古い描画のループが新しい章の表示後も無駄に回り続けていた。

## 決定

- `apply_position_frame` の入口（画像待ちループに入る前）でも世代を照合し、
  現在の世代と異なる場合は即座に `return` する。
- メインコールバックの世代チェックも維持する（二段構え）。
- 既存の挙動・API は変更しない。

## 選択肢と根拠

| 選択肢 | 判断 |
| --- | --- |
| 入口でも世代チェック（採用） | 無駄なループを即座に止められる |
| メインコールバックのみ | 古いループが最大 2000ms 回り続ける |
| `clearTimeout` で全ループを止める | 管理が複雑で、世代チェックで十分 |

## 影響

- 連続した章移動で、古い章の画像待ちループが即座に停止する。
- 位置適用の結果は ADR-0053 と同じ（世代号で古い適用は破棄される）。
- 追加依存は無い。
