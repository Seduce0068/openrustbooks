## 背景

ADR-0012〜0017 で読書位置・履歴を扱うようにしたが、本文の表示は CSS 固定で
文字サイズ・行間を変えられず、ダーク表示も無かった。また、localStorage に
保存した読書位置を消す手段が無かった。

## 決定

### 表示設定

- 文字サイズは 5 段階（1.0 / 1.125 / 1.25 / 1.5 / 1.75 rem、既定 1.125）。
- 行間は 3 段階（1.5 / 1.8 / 2.1、既定 1.8）。
- ダーク表示のオン・オフ（既定オフ）。
- 設定は localStorage の `openrustbooks:settings` に JSON で保存し、起動時に
  読み込む。壊れた値・範囲外の値は既定へフォールバックする。
- 設定は本ごとではなく全体で共有する。
- 適用は `.reader-container` のクラス（`reader-font-N`・`reader-line-N`・
  `reader-dark`）と CSS 変数（`--reader-font-size`・`--reader-line-height`）で
  行う。動的な `style` 属性は使わない。

### 読書データの削除

- `Clear data` ボタンで `openrustbooks:position:` で始まるキーを削除する。
- 削除後に状態メッセージ（削除件数）を表示する。
- 表示設定（`openrustbooks:settings`）は削除しない。

## 選択肢と根拠

| 選択肢 | 判断 |
| --- | --- |
| CSS クラス + CSS 変数（採用） | 再描画が確実で、インラインスタイルを増やさない |
| インライン `style` の動的更新 | 単純だが、今回の実装では変更が反映されないケースがあった |
| OS・ブラウザの設定に追従 | 追加の API とテストが増える |
| 設定を本ごとに保存 | 読書全体の好みとしては過剰 |

## 影響

- 文字サイズ・行間・ダーク表示を変更でき、次回以降も維持される。
- 設定は localStorage に保存され、外部送信は行わない。
- `Clear data` で読書位置は消えるが、現在開いている本の位置はその後の操作で
  再保存され得る。
- ダーク表示は本文領域のみで、アプリ全体のテーマには対応しない。
