## 背景

ADR-0006 の未決定「目次パネルの折りたたみ・検索」。
章数が多い EPUB ではドロップダウンから目的の章を探しにくい。

## 決定

- ツールバーに `<input id="reader-chapter-filter">` を置く
  （`aria-label="Filter chapters"`、type=search）。
- 章タイトルを部分一致（大文字小文字無視）で絞り込む。
- **現在表示中の章は、フィルターに一致しなくても一覧に残す**。
  `<select>` の選択状態を失わないため。
- 空文字のときは全章を表示する。
- 本を開き直すとフィルターはクリアする。

## 選択肢と根拠

| 選択肢 | 判断 |
| --- | --- |
| 部分一致フィルター + 現在章を保持（採用） | 検索性と選択状態の維持を両立できる |
| 完全一致 | タイトルの一部しか覚えていない場合に使えない |
| 現在章も絞り込む | 選択が外れ、現在位置が分からなくなる |

## 影響

- 章数が多い本でもタイトルで絞り込んで移動できる。
- 章移動・履歴・位置復元の挙動は変わらない。
- 追加依存は無い。

## 検証

- ヘッドレス Chrome 157 と `tools/verify-web-reader.py` の E2E 210 項目が
  5 回連続で成功。
- フィルター入力の存在、該当章が残ること、一致しない語では現在章だけが
  残ること、クリアで全章に戻ることを確認した。
- `cargo test --all-targets --locked` は 125 件成功。
- 6 ゲート（fmt / check / test / clippy / wasm32 × 2）と `trunk build` が成功。
- CI は billing issue で実行不可（ローカル検証で代替）。
