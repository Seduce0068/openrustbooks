## 背景

ADR が 0223 まで進む一方、`todo.md` の未着手には解消済みの高／中優先度項目が
残っていた。監査で ADR とコミットの実績を照合した結果、大半は既に実装済みで、
残るのは ADR の「未決定」に集約すべき判断だけだった。

## 決定

- 解消済みと判定した TODO を未着手から削除し、根拠 ADR を明記した完了エントリへ移動する。
- CI-H01 は billing 依存の外部要因として低優先度へ移動し、E2E 期待件数を
  246 から 253 へ統一する（根拠 `.github/workflows/ci.yml:6`）。
- D05 は「IPC マスク／DTO 境界は完了」「OS キーチェーン移行は未決定」に分割する。
- A05 + B01 + B02 は「CSP（B01 / B02）は完了」「UI 接続（A05）は段階 2 として残存」へ分割する。
- 残リスクは個別 TODO を新設せず、既存 ADR の「未決定」を唯一の追跡先とする。
- 既存の履歴 ADR と完了エントリは保持し、コード・E2E は変更しない。
