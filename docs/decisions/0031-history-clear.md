## 背景

ADR-0029 までで履歴一覧から任意の位置へジャンプできるが、履歴を消す手段が
無かった（ADR-0029 の未決定「履歴エントリの削除（個別削除・全消去）」）。
長く読み続けた本では履歴が上限（ADR-0019 相当の件数）まで積まれ、
一覧から目的の位置を探しにくくなる。

## 決定

### 履歴クリアボタン

- ツールバーに `<button id="reader-history-clear" aria-label="Clear history">`
  を置く。ラベルは "Clear"。
- クリックで**開いている本の**履歴を消す。他の本の履歴（localStorage の
  別キー）は触らない。
- 消した後は履歴に現在位置 1 件だけを残す。戻る・進むは不可になり、
  履歴一覧は disabled になる。
  - 現在位置を残す理由: 履歴を完全に空にすると、次の移動の起点が
    消え、戻る・進む・一覧の意味が失われるため。
- localStorage の当該本の履歴キーも更新する（現在位置のみの履歴を保存）。
  これでリロード後も履歴 1 件の状態が維持される。
- 履歴が 1 件のときは disabled にする。

## 選択肢と根拠

| 選択肢 | 判断 |
| --- | --- |
| 全消去ボタン（採用） | 追加依存なし、1 クリックで完了する |
| 一覧から個別削除 | ドロップダウンでは操作性が悪い（選択と削除の区別がつかない） |
| 履歴を完全に空にする | 現在位置の起点が消え、戻る・進むが壊れる |

## 影響

- 履歴を好きなときにリセットできる。
- 履歴の保存・復元の仕組み（ADR-0024）、エクスポート・インポート
  （ADR-0030）は変わらない。クリア後の履歴（1 件）も通常どおり
  バックアップの対象になる。
- 追加依存は無く、既存の `web-sys` 機能の範囲で実装している。
